# PySynoptic v0.3.0

## What's new

### What is it for?

Static Insights continues to explain the statically observable **Role** and
**Purpose** of modules, classes, functions, and methods. These deterministic
results remain backed by inspectable Evidence and qualitative confidence.

### How does it work?

The new deterministic **FlowExplanation** turns a callable's structural control
flow into a concise **How it works** summary. Hierarchical **Key Steps** expose
decisions, loops, exception paths, resolved calls, and outcomes without forcing
the user to read the entire Flow graph at once.

Selecting a Key Step opens the corresponding Flow view and highlights its node.
Callable CFG and FlowExplanation results are built lazily and cached, keeping
normal project navigation responsive.

### Optional AI-enhanced explanations

Users can explicitly ask an OpenAI-compatible or Ollama-compatible provider to
reformulate the deterministic How it works explanation. AI support is disabled
by default, never runs automatically, and does not replace the static result.
AI prose is clearly identified and never becomes Evidence or a source of truth.

## AI security and privacy

- raw Python source is not sent to providers;
- requests contain a structured representation derived from static analysis;
- quoted literals are redacted;
- names, symbols, and inferred purposes may remain and can be sensitive;
- remote endpoints require confirmation before transmission;
- API keys are read from the session or environment and are not persisted;
- requests are limited to 12,000 characters and responses to 2,000 characters;
- provider networking runs outside the Tk thread.

The existing static-analysis boundary is unchanged: analyzed project code is
never imported, executed, evaluated, launched in a subprocess, or inspected
through runtime loading.

## Downloads

Native, self-contained PyInstaller `onedir` archives are produced separately
for each supported desktop platform:

- `PySynoptic-v0.3.0-Windows-x64.zip`
- `PySynoptic-v0.3.0-Linux-x64.tar.gz`

Final SHA-256 checksums are published with the GitHub Release.

## Compatibility and limitations

- Python 3.11 through 3.14 remain supported for source installations.
- Windows and Linux archives remain native platform-specific builds.
- AI-enhanced explanations require a separately configured compatible service
  and may be incomplete or inaccurate.
- Dynamic Python behavior remains outside the guarantees of static call and
  flow analysis.
